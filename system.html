System 1 (1984)
About System 1.0: The original 1984 release, dumped from an original, mostly untouched disk. It was a single-tasking OS for the Motorola 68K CPU, bundled with MacWrite, MacPaint, and a Guided Tour. The 400k image has been tested and works in standard emulators.

System 2 (1985)
About System 2.x: Released in 1985. System 2.0 still used the flat MFS file system. The Hierarchical File System (HFS) was introduced only in System 2.1, specifically to support folders on the first Apple Hard Disk 20.

System 3 (1986)
About System 3.x: Introduced with the Macintosh Plus. This version brought HFS support to 800K floppy disks, along with SCSI support and AppleShare networking. System 3.2 was the last version that could run on a 128K Mac (with limitations).

System 4 (1987)
About System 4.x: Released in 1987. System 4.0 formally dropped support for the 128K Mac (requiring at least 512K RAM), added Mac SE support, revised the Chooser and Control Panel, and introduced the "bulging" Trash effect. System 4.1 added Mac II support and supported hard drives over 32MB.

System Software 5 (1987)
About System 5.x (System 4.2/4.3): Starting with this release, Apple unified all software under one version numbering system ("System Software 5.0"), though the core System file remained at version 4.2. This release introduced MultiFinder (multitasking and application switching) and added more color support.

System 6 (1988)
About System 6: System 6 finally brought version numbers mostly in sync. It added improvements to MultiFinder and LaserWriter drivers, and support for the 800k/1.44mb SuperDrive. System 6.0.3 is considered the first stable version. System 6.0.8 was the final and most popular release for classic Macs.

Warning: System 6.0.6 was not officially released due to a bug. It is included here for historical preservation.
